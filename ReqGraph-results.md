## 2026-09-25 22:30 - Пример прогнан, README со схемой, лицензия – проект готов к публикации

- после перезагрузки тесты прошли без изменений. Пример `examples/referral` прогнан из командной строки, итог записан в [result.md](examples/referral/result.md): восемь требований с источниками, три вопроса заказчику с ответами, три задачи, трассировка;
- в прогоне видны все механизмы: выдуманная сумма и «быстро» пойманы на первой попытке, вопросы ушли через interrupt, ответ заказчика расширил контекст новым фрагментом `glossary.device`, забытые при декомпозиции R5 и R8 пойманы проверкой покрытия;
- схема графа по стандарту `a-veg-diagrams`: исходник [graph.mmd](docs/diagrams/src/graph.mmd), рендер `mmdc` в `docs/diagrams/images/graph.png`, цвета узлов из палитры – модель синяя, проверки бирюзовые, человек зелёный, служебные оранжевые. Узел `check_coverage` получил короткую подпись: с длинной ромб раздувался на полсхемы;
- **схема сверяется с кодом тестом** [test_docs.py](tests/test_docs.py): рёбра на картинке должны совпадать с рёбрами скомпилированного графа, иначе тест падает;

- [README.md](README.md): зачем проверки кодом, схема, таблица узлов, какие механизмы LangGraph где работают, пример прогона, запуск без ключа и с настоящей моделью, ограничения. Из подсказок по провайдерам убран GigaChat: в списке `init_chat_model` его нет;
- LICENSE MIT. Тестов 13, все проходят; кода с тестами – 842 строки.
