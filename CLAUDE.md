# Правила проекта ReqGraph

## О проекте

Граф агентов на LangGraph: из сырого запроса заказчика – требования с источниками, вопросы заказчику и задачи с трассировкой. Готовится к публикации на GitHub как проект-пруф, поэтому код и тексты уходят наружу.

## Лог

- Файл: `ReqGraph-results.md` в корне проекта, новые секции сверху, формат `## YYYY-MM-DD HH:MM - описание`.

## Окружение

- venv `.venv`, Python 3.13. Запуск: `.venv/Scripts/python.exe -X utf8 -m reqgraph examples/referral/request.txt`, тесты: `.venv/Scripts/python.exe -X utf8 -m pytest -q`.
- Без ключа модели граф работает на сценарной заглушке `examples/*/script.yaml`; настоящая модель – флагом `--model провайдер:модель`.

## Правила кода

- Проверки требований – в `reqgraph/checks.py`, детерминированные, без обращения к модели: промпт просит, проверка гарантирует.
- Докстринги и комментарии по-русски, идентификаторы по-английски.
- После правки графа – прогон тестов.
