# Память проекта ReqGraph

- Создан 25.09.2026. Автор – Евгений Валентюк.
- Цель: показать оркестрацию агентного графа на LangGraph на задаче системного аналитика – сырой запрос → требования с источниками → вопросы заказчику → задачи с трассировкой.
- Стек: langgraph 1.2.12, langchain 1.4.2, langchain-core 1.6.5, pydantic 2.13, Python 3.13.
- Живой прогон на настоящей модели не делаем – решение автора от 25.09.2026. Демонстрация идёт на сценарной модели, README говорит об этом прямо.
- Коммиты подписываются личной почтой через локальную настройку репозитория: Evgeny Valentyuk, e.valentyuk@yandex.ru.
- Репозиторий: https://github.com/EValentyuk/ReqGraph, публичный.
